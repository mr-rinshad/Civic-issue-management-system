# 🏛️ Smart Civic Issue Reporting System

A web-based platform designed to bridge the gap between citizens, local administrators, and municipal departments. The system streamlines the process of reporting, verifying, and resolving public infrastructure issues—such as potholes, garbage accumulation, broken streetlights, and water leaks—through location-tagged complaint submissions, image verification, and real-time status tracking.

---

## 📌 Project Overview

* **Problem:** Civic issues are often handled through slow, manual channels, leaving citizens without tracking visibility and authorities without an efficient verification system.
* **Solution:** A centralized web portal where citizens submit issues with GPS data and photos, local administrators verify and route them, and responsible departments resolve the problems with photo proof.
* **Core Goal:** Improve municipal accountability, speed up issue resolution, and keep the public updated in real time.

---

## 💻 Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
